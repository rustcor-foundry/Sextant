# Sextant Browser installer

Windows installer built with [Inno Setup](https://jrsoftware.org/isinfo.php).

## Build

From the repo root, after the toolchain is set up:

```powershell
# 1. Release build of the core-loop crate (+ its runtime DLLs).
cargo build --release -p sextant-browser --manifest-path rust/Cargo.toml

# 2. Compile the installer (ISCC = the Inno Setup command-line compiler).
iscc installer\sextant.iss
```

The setup executable is written to `dist\sextant-browser-setup-<version>.exe`.

`build.ps1` runs both steps.

## What it installs

- `sextant-browser.exe` and the runtime DLLs that ship next to it
  (e.g. `html2md.dll` from distill) into `%LOCALAPPDATA%\Programs\Sextant Browser`
  (per-user, no admin) — or `Program Files` if the user elevates.
- A Start-menu shortcut, an optional desktop shortcut, and an optional
  "start when I sign in" entry (per-user `HKCU\…\Run`).
- An Add/Remove-Programs uninstall entry (generated by Inno).

## Lifecycle

The browser runs single-instance and minimizes to the system tray on close
(left-click the tray icon to reopen, `Ctrl+Q` to quit). A second launch — e.g.
the autostart entry plus a manual launch — focuses the running window instead
of opening a second one.
